# Capturas de pantalla

Capturas que usan el libro y la web (`\captura{nombre}{...}` en LaTeX). Cada una se guarda aquí como `nombre.png`; mientras falte, el libro y la web muestran un recuadro que indica qué imagen debe ir.

La lista de capturas, qué debe mostrar cada una y cómo obtenerla está en [docs/05-validacion-sap2000.md](../docs/05-validacion-sap2000.md#5-capturas-de-pantalla).
