## 4.1 El mismo cálculo para cada barra

La geometría de una barra depende solo de las coordenadas de sus dos nodos:

$$
L = \sqrt{\Delta x^2 + \Delta y^2}, \qquad
  c = \frac{\Delta x}{L}, \qquad s = \frac{\Delta y}{L}.
$$

Para el ejemplo A, con tres barras, podríamos copiar tres veces el cálculo del
[capítulo 2](/capitulos/cap02_primer_notebook). Pero una armadura de cubierta típica tiene entre
20 y 50 barras, y la de un puente, varios cientos. Copiar el cálculo sería
tedioso y, sobre todo, una fuente segura de errores: basta con olvidar
cambiar un número en una de las copias.

Lo que necesitamos es escribir el cálculo *una sola vez* y pedirle a
Python que lo repita para cada barra del diccionario `barras`.

## Repaso y resumen del capítulo

- El bucle `for` repite el bloque sangrado debajo de él para cada elemento de una colección.
- Al recorrer un diccionario, `for` entrega sus claves; `.items()` entrega la clave y el valor a la vez.
- Un acumulador empieza con un valor inicial y crece en cada repetición con `+=`.
- La geometría de todas las barras se guarda en un diccionario nuevo, `geometria`, con el número de barra como clave. Los datos de entrada no se modifican.
- En las f-strings, `:7.3f` fija el ancho y los decimales de una columna, y `:>5` alinea a la derecha.
- Para toda barra debe cumplirse $c^2 + s^2 = 1$.
